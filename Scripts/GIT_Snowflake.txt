-- Configure Snowflake, VSC, GIT , GITHUB

Development environment:

VSC -- Write SQL, Python, dbt and manage files
GIT -- Version Control
GITHUB - Code Repo


1. Write and execute Snowflake SQL directly from VS Code.
2. Connect VS Code to Git and GitHub.
3. Track changes to your SQL scripts and dbt models.
4. Push your code to a GitHub repository.
5. Pull the latest changes whenever you work on another machine.
